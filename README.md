# cap01

The cap01 product workspace: tools for habits, reflection and personal growth.

The implemented app lives in `apps/web`, built with React Router and Vite.
An API and Expo mobile client are planned; they have no implementation here yet.
The public Astro website lives separately in `jterrazz/cap01-website`.

```sh
npm ci
npm run dev
```

Open http://localhost:4320. The preview stores data only in this browser.
Read the [product corpus](docs/README.md) and [web guide](apps/web/docs/README.md).
