# State and names

What is built, what is not, and why the tree does not spell "capitaine"
everywhere.

## State

Scaffold-complete, product-empty. The commit log spans September 2023 to
June 2024 — the scaffolding, the quality pipeline, the stack naming — then
an August 2025 README update. Nothing else has moved since.

## Former names

Capitaine was called Life Captain before, and Daily Rise before that. Both
survive in identifiers, and renaming them is a change nobody has made:

| Identifier       | Where                                   |
| ---------------- | --------------------------------------- |
| `daily-rise-api` | the npm package name (`package.json`)   |
| `life-captain`   | the Makefile and Docker Compose project |
| `life_captain`   | the development database                |
